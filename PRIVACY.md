# Privacy Policy — Dev Toolbox

Last updated: 7 November 2026

Dev Toolbox runs entirely on your own computer, as a local process that Claude Code starts.

- **No data is collected.** The plugin has no analytics, telemetry or logging.
- **No data is sent anywhere.** The server makes no network requests.
- **No data is stored.** The server doesn't read or write files. Your input exists only in memory while one tool call runs.
- **No third parties.** The plugin calls no outside services or APIs.

The text you pass to a tool (for example, text to hash) goes from Claude Code to the local server, and the result goes straight back. What Claude itself does with your conversation is covered by Anthropic's own privacy policy, not this one.

Questions: open an issue on this plugin's GitHub repository.
