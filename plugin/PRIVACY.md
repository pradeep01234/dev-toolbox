# Privacy Policy: Dev Toolbox

Last updated: 7 November 2026

Dev Toolbox connects Claude to a hosted MCP server at `https://dev-toolbox-jade-rho.vercel.app/api/mcp`.

- **What is sent:** only the input of the tool Claude calls (for example, text to hash or a timestamp to convert). It travels over HTTPS.
- **What is stored:** nothing. The server handles each request in memory, returns the result, and forgets it. It writes no files, has no database and does not log request contents.
- **No accounts and no tracking:** there is no sign-in, no analytics and no cookies.
- **No third parties:** the server calls no other services. It runs on Vercel, which, like any web host, may keep basic request metadata (such as time, IP address and URL path) for a short time to operate its platform. See Vercel's privacy policy at https://vercel.com/legal/privacy-policy.
- **Personal data:** the plugin doesn't ask for personal data. Don't send secrets or personal information to these tools.

What Claude itself does with your conversation is covered by Anthropic's privacy policy, not this one.
